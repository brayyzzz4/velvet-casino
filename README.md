# Velvet Casino

A Netlify-ready social casino interface using play credits only.

## Deploy to Netlify

1. Open Netlify and choose **Add new site → Import an existing project**.
2. Choose GitHub and select **brayyzzz4/velvet-casino**.
3. Leave the build command blank and set the publish directory to **.**.
4. Deploy.

This demo stores accounts and balances in each browser's local storage. It does not process real money, deposits, withdrawals, or cash prizes.
